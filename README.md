# 🖥️ Mi Portafolio Personal

### Una página web construida con HTML, CSS, JavaScript y Bootstrap

Este es mi sitio personal donde me presento y muestro mis proyectos. Diseñado completamente con tecnologías frontend para ser ligero, responsivo y fácil de personalizar.

## 🚀 Tecnologías utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos personalizados
- **JavaScript (Vanilla)** - Interactividad y dinámicas
- **Bootstrap 5** - Sistema de grillas, componentes y estilos predefinidos

## 📌 Características

- ✅ Diseño completamente responsivo (mobile first)
- ✅ Tarjetas interactivas para mostrar proyectos
- ✅ Sección "Sobre mí" con presentación personal
- ✅ Enlaces a redes sociales
- ✅ Estilo moderno y limpio
